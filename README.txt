A.I.D.A. — Anguilla Inland Revenue Department Assistant

1. Install Python and open a terminal in this folder.
2. Install packages:
   pip install -r requirements.txt
3. Rename .streamlit/secrets.toml.example to .streamlit/secrets.toml
4. Put your NEW Gemini API key in secrets.toml.
5. Run:
   streamlit run aida_app.py

The CSV must remain in the same folder as aida_app.py unless you upload a replacement from the sidebar.
